5. KURULUM – A) SIFIRDAN YENİ KURULUM (boş veritabanı)
======================================================================
1) cPanel → MySQL Veritabanları: yeni veritabanı + kullanıcı oluşturun, kullanıcıya TÜM YETKİLER verin. Şifreyi kimseyle paylaşmayın.
2) Dosya Yöneticisi → public_html → zip'i yükleyin → "Extract" (çıkar). index.php doğrudan public_html içinde olmalıdır.
3) Tarayıcıda https://rafimda.com.tr/install/ adresini açın. Sihirbaz gereksinimleri denetler; veritabanı bilgilerini girin,
   yönetici hesabını oluşturun. "Demo veri" seçeneğini CANLIDA İŞARETLEMEYİN (demo ürünler gerçek değildir).
   Sihirbaz config/env.php dosyasını yazar ve şemayı kurar. Veritabanının gerçekten BOŞ olduğundan emin olun.
4) Yönetici paneline girin (varsayılan /admin). Modüller → aşağıdaki sırayla "Kur" + "Etkinleştir":
   rafimda-theme → rafimda-vendor → xml-hub → marketplace-hub → rafimda-showcase → rafimda-campaign → rafimda-legal →
   rafimda-invoice → rafimda-social → rafimda-rafi → (rafimda-dealer: kurulabilir, ancak PASİF kalır; etkinleştirme yazılı onay ister)
   Ayrıca FriSay'in "question" (soru-cevap) ve "reviews" (yorumlar) modülleri kurulu ve etkin olmalıdır.
5) Bölüm 6'daki yapılandırmayı yapın; Bölüm 8'deki kontrolleri uygulayın.
6) install/ klasörü: kurulum bittikten sonra sihirbaz env.php varken kendini kapatır; klasörü yeniden adlandırma/silme kararı sizindir.

======================================================================
5. KURULUM – B) MEVCUT SİTEYİ GÜNCELLEME (rafimda.com.tr'de FriSay zaten kurulu, config/env.php VAR)
======================================================================
1) Bölüm 4'teki yedekleri alın (ZORUNLU).
2) Zip'i public_html'e yükleyip çıkarın. Paket config/env.php İÇERMEZ → mevcut env.php korunur. img/products/ içeriğine
   dokunulmaz. ÜZERİNE YAZILACAKLAR: çekirdek PHP/şablon dosyaları, .htaccess, robots.txt, img/logo*.png, img/favicon*.ico,
   img/shopLogo.png, img/default.jpg. Mevcut .htaccess'inizde özel kural varsa yüklemeden önce yedeğini alıp karşılaştırın.
   Toplu silme YAPMAYIN.
3) Sihirbaz çalışmaz (env.php var). SSH veya tek seferlik cron ile salt-okunur ön kontrol:
     cd ~/public_html
     RAFIMDA_ENV=live RAFIMDA_LIVE_CONFIRM=EVET-CANLI-DB RAFIMDA_LIVE_DB_NAME=<env.php'deki DB_NAME> php deploy/live/bin/live-preflight.php
4) Migration PLANI (hiçbir şey yazmaz):  ... php deploy/live/bin/live-migrate.php
5) Uygulama (yalnızca yedekten sonra, sizin kararınızla):
     RAFIMDA_BACKUP_CONFIRM=EVET-YEDEK-ALINDI RAFIMDA_MIGRATE_CONFIRM=EVET-MIGRATION RAFIMDA_BACKUP_FILE=/home/KULLANICI/yedek.sql \
     RAFIMDA_ENV=live RAFIMDA_LIVE_CONFIRM=EVET-CANLI-DB RAFIMDA_LIVE_DB_NAME=<DB_NAME> php deploy/live/bin/live-migrate.php --apply
   Araç yalnızca CREATE TABLE IF NOT EXISTS ve korumalı ADD COLUMN yapar; DROP/TRUNCATE/DELETE reddedilir; FriSay tablolarına dokunmaz.
6) Doğrulama (salt-okunur): ... php deploy/live/bin/live-verify.php --out=logs/live-verify.md  → 0 FAIL beklenir.
7) Panelden modülleri Bölüm 5-A/4'teki sırayla kurup etkinleştirin (ayar tohumlama panel kurulumunda yapılır).
SSH yoksa: cPanel Cron'a komutu "... > /home/KULLANICI/cikti.txt 2>&1" ile bir kez ekleyin, çıktıyı okuyun, cron'u silin.
