# rafimda-theme

Mevcut FriSay temasının (theme4) üstüne Rafımda markası (lacivert/turuncu), ana sayfa hero'su ve satıcı bağlantıları ekler. Çekirdeğe ve tema dosyalarına dokunmaz. Veritabanı tablosu yoktur; kurulum migration çalıştırmaz.
Kancalar: home_slider, footer, mobile_menu, auth_register (theme4'ün çizdiği kancalar). Satıcı bağlantıları yalnızca `rafimda-vendor` etkinse görünür.
Yönetici paneli: Sistem > Rafımda Tema (hero/bağlantı aç-kapa, başlık, entegrasyon durumu).
